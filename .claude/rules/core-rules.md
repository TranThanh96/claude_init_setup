# Core Rules
- Read the relevant code before changing it; don't guess the API.
- Run tests after every change; don't report "done" when tests aren't passing.
- Large changes (>3 files or an interface change): present a plan first and wait for approval.
- Don't add a new dependency without asking first.
- Prefer the minimal fix; don't refactor outside the task's scope.
- After finishing a task with tests passing, remind me to run /update-memory-bank.
